## Agent skills

### Issue tracker

Issues and specs are GitHub issues on `snacker-tracker/interface`, used through `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

Two contexts, listed in `GLOSSARY-MAP.md`: Snacker Tracker (`GLOSSARY.md`, `docs/adr/`) and stepdag (`stepdag/`). See `docs/agents/domain.md`.
